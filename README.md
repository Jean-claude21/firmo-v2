# Firmo

Le bureau administratif du petit professionnel, dans sa messagerie. Il dicte sa vente ou envoie la
photo de son devis papier ; Firmo lui renvoie un devis, une facture ou un reçu professionnel, et le
suit jusqu'au paiement.

> Le calcul est à lui. La présentation est à nous.
