# Hypothèses — Firmo

Le porteur a décidé le 2026-11-14 de considérer ces hypothèses comme validées pour construire la V1.
Les seuils restent consignés pour la mesure en production ; ils ne seront pas modifiés après lecture.

| # | Hypothèse | Mesure | Seuil |
|---|---|---|---|
| H1 | Les artisans qui vendent à des clients formels utilisent Firmo chaque semaine | organisations actives en semaine 3 / inscrites | ≥ 40 % |
| H2 | La lecture d'une dictée ou d'une photo est fiable | fidélité de lecture | ≥ 90 % des valeurs |
| H3 | Un artisan partage lui-même un document sans aide | `document_shared` dans les 7 jours | ≥ 50 % |
| H4 | L'offre est payée après l'essai | abonnés / organisations ayant épuisé l'essai | ≥ 30 % |
